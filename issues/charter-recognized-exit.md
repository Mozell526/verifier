## 1. Goal & Definition of Done

- Goal: 钉死这块东西的安放方案。主语是用户贴出的那一块，不是「第二问」。
- Done:
  1. 每个根因一个 issue + 现行出口原文 + 已锁 Consensus；
  2. architect 独立重读协议和现行出口后写 Consensus；
  3. 交给用户的是一句方案：这块东西的出口放在哪、人看见时是不是一个 judge 结果标签、它不是哪三个口。

「方案」在本轮的工作定义（可证伪）：

1. 能用一句话说清：用户认得的这一块，它的出口放在哪一层、哪一格；
2. 这一句的主语必须是这块东西本身，不得先把它改名为「第二问」再推安放；
3. 必须同时说清：它是不是只补 not_fulfilled，是不是 fulfilled 的第四个词，是不是 NE，是不是新增一个判定再写的标签；
4. 若「新增一个 judge 结果标签」只描述安放、不给这块东西改名，必须把这两层拆开；
5. 不得再交一份「四个口都不能」而不给方案句。
