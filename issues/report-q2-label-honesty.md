## 先答这一句

是。若打开第二问自己的格子，看结果的人会多看见一格字。这一格字就是一个结果标签。

上一轮用「谁写」去禁这个叫法，这一轮作废。承认叫法，不等于批准「判定再写一个词」，也不等于本轮打开。

章程要求分开答、不得再焊回一句：

```text
人看见的：结果上是不是多了一格字     是
谁写下的：是不是同一张嘴再判一次     不是
进哪张嘴：是不是改写办成了 / 没办成 / 说不清     不是
```

## 四个点名口

| 点名口 | 整句能不能当宿主 | 拆开之后留下什么 |
|---|---|---|
| 只是没办成的补充 | 不能 | 什么都不留。第二问不是失败原因 |
| 新增一个判定结果的标签 | 不能整句当宿主 | 看见层那截留下：结果上多一个兄妹标签。判定再写那截仍死 |
| fulfilled 从 3 态扩到 4 态 | 不能 | 什么都不留。第四个词仍是第一问的嘴 |
| 放到说不清里面 | 不能 | 什么都不留。说不清答的是这一次办没办成现在说不准 |

人现在只能看见第一问，是因为第二问还没有自己的格子。不是因为它属于这三个词里的某一个，也不是因为它只属于没办成。

「没圈中 B」不是没安放。圈中 B 才是没安放。
