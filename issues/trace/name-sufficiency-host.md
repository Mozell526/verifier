# 充分性落到 judge：两问，一张嘴

042–045 的原则正文仍在 `name-sufficiency.md`。本文件只写 **judge 自己怎么说话**。
不要把针表抄进定义。

## 看什么

1. 用户问句（只取一个字段：`user_text` 优先，其次同源 `query`）
2. live 交出来的字段和值
3. 该字段已经拍过的证据标准（姓名维 = 1A；单号维 = 本值）

## 不看什么

混合包 `role`、题型名、残句、虚词表、系统自报、`is_supported`、canvas、341 准确率、样本 ID。

## 两问

```text
Q1  这个交出来的值，够不够撑住它自己那一维？
Q2  有没有足够证据证明：用户要的就是这一维，并且这一维已经按 Q1 交齐？
```

Q2 充分 ≠ 必要。本轮唯一授权的充分性测试：

```text
恰好一个字段，值等于整句，且该字段有授权标准（姓名 / 单号）
```

## judge 的三态

| 态 | 何时 | 意思 |
|---|---|---|
| fulfilled | 测试打中，且 Q1 过 | 用户要的就是这一维，并且交齐了 |
| not_fulfilled | 测试打中，且 Q1 不过 | 用户要的就是这一维，但值撑不住该维标准 |
| inherit | 其他所有情况 | 证据不够。LLM 照旧。当前失败还失败，当前成功还成功 |

inherit 是正式出口。覆盖所有情况 = 每一格都有去处，不是 = 全部改判对。

## 和 overlay 的分界

044 的 overlay 从不过失败：它只是补丁，没有资格声称「我认出这是假的」。

judge 不是补丁。充分性测试打中时，剩下的唯一问题就是 Q1。
共展 / 豆芽走 NF，是姓名维标准没过，不是假名识别器。
