# Report — 姓名场景：这一轮定的是原则和边界，不是新分数

用户要的是姓名类场景的泛化，并且在内存里对照 judge。硬要求：抽象 / 原则 / 标准 / 边界，排除歧义，每个输入都有去处。只盯 1A / 4A。没改判定，没改提示。

上一口「整句被收成一个身份」你已经否掉气质：看似没规则化，本质是规则化，扩散到别处会失败。本轮不再把它当架构卖。

## 先讲原则，再用例子

只评一件事：用户要的事，系统办成了没有。

- 问句 = 用户要什么
- 系统交出来的条件 = 系统实际做了什么
- 不能从问句发明成功

对任何一句，只问三件事，不问这是「姓名题」还是「保单题」：

1. 系统交出来的每个值，是不是问句里的连续原文？
2. 把这些原文挖掉之后，问句还剩字吗？
3. 交出来的东西里，有没有姓名或单号？姓名若出现，过不过已经拍过的 1A 门（2–4 个汉字、有姓、不是产品/地址）？

只有三态，没有「看情况」：

| 态 | 意思 |
|---|---|
| 主动改成功 | 这口有把握：身份对象已经按原文交齐 |
| 主动改失败 | 这口本轮不用。一用就是在声称「我认出这是假的」 |
| 不改判 | 证据不够，或超出这口的授权。当前失败还失败，当前成功还成功 |

不改判不是漏洞。它是所有还没被授权说话的情况的正式去处。

## 用例子把边界钉死

| 用户说的 | 系统交出来的 | 这口怎么走 | 为什么 |
|---|---|---|---|
| 杨杰 | 姓名=杨杰 | 主动改成功 | 值就是整句，残句空，过 1A 门 |
| 王坤林 | 姓名=王坤林 | 主动改成功 | 和杨杰同侧，不因为这是长尾就另眼看 |

| 张忠波保单号 | 姓名=张忠波 | 不改判，保持当前成功 | 还剩「保单号」。不改判所以不会误杀 |

| 李明重疾险（parser 将来交齐） | 姓名=李明，产品=重疾险 | 主动改成功 | 两个对象一起把问句盖住，残句空，有姓名 |
| 共展 | 姓名=共展 | 不改判，保持失败 | 残句空，但不过 1A 姓氏门。**不是**「已经会认假姓名」 |

「能覆盖所有可能出现的情况」= 上面每一格都有去处，不是 = 全部改判对。

昊轩 / 去年 / 称谓 / 格式外：继续停在不改判。本轮不代选。

## 这和规则表差在哪

被否掉的形状是：先看这是哪种题（人名+保单、四字名、裸词…），再查表。新句子来了就再加一行。

这一口不看题型，不看混合包角色，不剥「的 / 查一下 / 保单号」，也不主动改失败。新句子来了，还是问上面三件事。答不出就停在不改判，而不是新开一条「某某题型」。

上一口「值必须等于整句」看起来也没有题型名，但出手条件是三个死门槛：只能一个字段、只能一个值、值还得等于整句。杨杰能过，红莲保单不能过，李明重疾险也不能过。那是局部地板，不是原则。本轮把它降成特例：恰好一个字段且值=整句时，对象覆盖会退化成它。

对象覆盖和整句门在冻结集上逐行标签相同。原因不是换了个名字：冻结痕迹里几乎没有「多个对象一起把问句盖住、残句还为空」的身份题。混合包没有多字段行。集 A 唯一对齐且残句空的多字段题是「综拓潜客」，它没有身份对象，两口都不改判。

原则比整句门多出来的手，只在合成探针上看得见：

- 「李明重疾险」交齐姓名+产品 → 对象覆盖改成功；整句门因字段多于 1 不改判
- 两个单号连写 → 同上

这两格不准算进混合包准确率。它们证明的是边界，不是现实分布。

所以：本轮赢的是「何时不许出手」，不是表上的数。混合包 41 条对上，不是发版理由。题型机也曾对上 41 条，形状已经被否。
