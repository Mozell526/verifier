# Charter — 开第二问的格子，是不是就是新增一个结果标签

> 本轮只辩用户这一句：开第二问自己的格子，本质上不就是新增一个 judge 结果的标签吗？
> 并在这句话成立或不成立之后，重新安放四个点名口。不改代码，不改协议正文，不改前端。
> 006–065 已有 Consensus 不重开其对错，但 065「B 口不能叫标签」这一句本轮可以打。
> 号段改到 070–073：066 已被 `charter-judge-agent-t4.md` 占用。

## 1. Goal & Definition of Done

- Goal: 钉死「开格子」和「新增一个结果标签」是不是同一件事；若是，它还是不是 NF 补充 / 3 扩 4 / 放进 NE。
- Done:
  1. 每个根因一个 issue + 现行出口原文 + 「人看见的那一格」对照；
  2. architect 独立重读后写 Consensus；
  3. 交给用户的是：开格子算不算多一个标签、这个标签住在哪张嘴、四个旧口还死不死。不是字段名，不是本轮改表。

本轮必须分开答、不得再焊回一句：

```text
人看见的：结果上是不是多了一格字
谁写下的：是不是同一张嘴再判一次
进哪张嘴：是不是改写办成了 / 没办成 / 说不清
```

「实现位置」在本轮的工作定义（可证伪）：

1. 能指出：若打开第二问自己的格子，看结果的人会不会多看见一格字；
2. 能指出：这一格字是不是第一问那三个词里的某一个，或第四个词；
3. 能指出：这一格字是不是判定再填的；
4. 不得把「以后若打开」写成批准上线。

## 2. Oracle

- **对错尺子**：`spec/alg/fulfilled.md` 第一章、`spec/alg/product-function.md` §1 / §6–10、`spec/alg/authority.md` §8.3、`spec/info-volume.md`、用户标注的两问结构、046–064 / 058–061 Consensus。
- **本轮可打**：065 把「新增 judge 结果标签」整句判死、并禁止把它叫成标签。
- **不是 oracle**：canvas、准确率、字段名、`is_supported`、姓名/年/天气类型表。

已锁、本轮不得重开题面：

```text
第一问（已经有）
  只看一件事：这一次，用户要的事办成了没有
  单位：这一次请求 × 这一次交付
  不看：产品把这件事立住了没有
  不区分：没给到的原因
  出口：办成了 / 没办成 / 说不清

第二问（出口还没有）
  只看一件事：用户要的这件事，产品把它立成自己会做的事了没有
  对象：仍是第一问那一件
  单位：这件事 × 产品事实
  产品事实从哪来：已经裁完的能力/职责判断，及其依据资料
  不看：这一次交付；这一次承不承认 / 尽没尽力
  出口：立住了 / 没立住 / 说不清
```

内部手柄不宣布采用为对外题面。
