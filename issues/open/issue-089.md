用户本轮把主语钉死：

认得的那一个，就是用户贴出的这一块：这件事 × 产品事实，出口是立住了 / 没立住 / 说不清。

085–088 的方案句主语是「开第二问自己的格子」。那句若成立，先得承认「第二问」是这块东西的名字。用户不认这个名字。从「两问同级 / 兄妹标签」推出「所以新增一个 judge 结果标签」，是在用用户不认的外号做桥梁。

fulfilled 继续在。用户问的是「按照 fulfilled 的定位」。fulfilled 是已经在的那一格字，答办成了没有。它是对照物，不是把这块东西改名为「第二问」的理由。

### Reasoning

本号站住。主语问题是真的，而且是本轮其它三号能不能写的前提。

1. **用户本轮钉死的是这块东西，不是一个外号。** 章程原文是「我认得东西从头到尾只有这一个，而不是你说的什么第二问」，后面整块定义才是对象。085-088 的方案句要成立，先得承认「第二问 / 兄妹」是这块东西的名字，再用「两问同级」去推「所以新增一个 judge 结果标签」。这座桥用的是用户不认的外号。本轮若再沿用 088，就是先改名再推安放。

2. **040 锁的是内容，不是命名权。** 040 Consensus 把这块东西写成「第二问」，并写下「不得为了更好答第二问把对象切粗或切细」。后一句是禁切对象，不是给它施洗。章程 §2 允许本轮打「把这块东西叫做第二问再推出安放」，不许重开对象 / 单位 / 不看什么 / 出口手柄。所以本号只换主语，不重判 040 的切法。

3. **fulfilled 还在，只证明对照物还在。** `fulfilled.md` §1 继续只评「这一次，用户要的事办成了没有」。人现在看见的评估字也只有这一格（`status` / `fulfillment_status` / 矩阵 Status）。这是对照，不是把这块东西改名为「第二问」的理由，更不是「所以没有这块东西」的理由。

4. **丢掉外号不得偷换成「没有这块东西」。** 040 已经锁住「这件事 × 产品事实」和三个内部手柄。本号若写成「用户不认第二问，所以没有出口可安放」，就是把命名失败兑成对象消失。那是本号自己写的失败条件。

5. **安放必须从这块东西自己的单位和出口推。** 单位是「这件事 × 产品事实」，不看这一次交付；出口是立住了 / 没立住 / 说不清。可以引用 047 / 058 / 060 / 061 已经锁死的内容。不可以用「因为这是第二问 / 兄妹问」当因为。

不整号 escalate：主语能在本号锁死。打开与否仍是 061 / 章程 §4，不在本号代选。
