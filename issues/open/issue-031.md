## Verifier Discovery

029 钉题面歧义。030 钉对象和具名词表。本 issue 分清：本轮角色能锁什么，不能锁什么。

用户要求「没有任何歧义」。章程把无歧义收成三条可证伪约束，不是「任何人第一眼不会读错」。角色若把某一句口语宣布为已经零歧义的正式题面，就是 024 禁止的代选。

- 第四态 / partial
- 「尽力了」= 办成了

- 「缺口在哪一侧」作主问
- 是/不是 对含混谓语作主词表

### 本轮若成立，锁进结构，不锁进终句

还活着的只有这一个结构：

- 对象：是不是「定位内尚未具备」
- 词表：定位内尚未具备 / 不得叫这个名字 / 材料不够判这一点
- 边界：漏做、职责外、对象不成立，都不得叫正名
- 与第一问正交，不回写办成 / 没办成

这是 015 / 024 还活着的家族，用 029 的翻面测试收紧了题面。

下面这些看起来像「更没有歧义的句子」，本轮仍不得宣布采用：

- 「这种事，是不是产品该有、但当前产品里还没有的」
- 「用户要的这种事，是不是定位内尚未具备」
- 任何把 030 结构直接念出来的中文

它们可以当结构的验算句，证明家族能被说清楚。验算句不是对外题面。024 已经写过：验收过关只证明家族，不证明这几个字能贴出去。

### 必须交给用户的三件事

1. 要不要对外看见第二问。不要，则停在 013 已知限制，fulfilled 维持原样。
2. 若要，用户自己写一句。必须通过章程 §1 三条，且遵守 030 题面约束。角色不得代拟终句，也不得宣布采用「办不了吗 / 办得了吗 / 该有但还没有」。
3. 现在改不改评测结果的结构。改则必须同时处理 015 已写的归因后果。本轮红线禁止代选。

现在先不定：去年算不算核心、称谓认不认、格式外算不算单号。那些是个案适用，不是这一层抽象。

### 可证伪
