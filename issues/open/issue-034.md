**Class**: boundary

## Verifier Discovery

032 钉单位泄漏。033 钉「单位 + 不看 + 三态」。本 issue 分清：本轮角色能锁什么，不能锁什么；以及用户这一轮到底要不要再定东西。

用户上一轮已经问过「你想让我定啥呢？我没看懂」。031 把「请自己写一句」交回去，是把抽象没锁完伪装成用户作业。本轮禁止再这么做。

### 角色可以锁、也必须锁的

032 / 033 的结构：

- 两问同级
- 差在单位，不差在语气
- 各有一条「不看」
- 第二问三态按产品里现成的那一档切，不按这一次交付切
- 023 的 2×2 只是交叉表
- 015 的承认是第三问，已死

这些不是用户作业。过不了章程四条，就还没锁住，不能交回用户。

### 角色不得代选、本轮也不再催的

章程 §4 仍停住：

1. 要不要对外看见第二问
2. 用哪一句中文当对外题面
3. 现在改不改 schema
4. 去年 / 称谓 / 格式外

看见与否、改不改表，只在报告里记「仍停住」。不要写成「请先定这三件事」。
对外那一句尤其不得代拟，也不得宣布采用「现成有 / 现成没有 / 该有但还没有 / 定位内尚未具备 / 办不了吗」。

### 继续死（不改 oracle 就不能重开）

- 第四态 / partial
- 「尽力了」= 办成了
- 用说不清装长期现成没有
- 拿系统自报当标签
- 「正确承认尚未支持」作主问
- 「尽力了吗」作主问
- 「放对地方 / 站得住」作主问
- 「办得了吗 / 今天就办不了吗」作主问
- 「认不认」作单独主问
- 「缺口在哪一侧」作主问
- 是 / 不是 对含混谓语作主词表
- 030「没有完成它的办法」当无歧义定义
- 让用户自己写一句，当作本轮抽象已经完成

### 用户若要否，应该否哪一条

若 033 的结构不对，指出下面哪一条多了或少了，不要再换一句口语来否：

1. 第二问的单位是「这种事 × 产品里现成的那一档」
2. 答第二问时不看这一次交付
3. 「现成没有」进不了漏做，也进不了职责外 / 对象未成形
4. 第一问办成了，不能自动排除「现成没有」
5. 023 的 2×2 只是交叉表，不是第二问

### 可证伪

Consensus 若出现下面任一情形，本 issue 被越权：

- 把任何一句中文写成「本轮正式题面」
- 把「现成有 / 现成没有」宣布为已采用的对外词
- 要求用户先交一句题面，否则结构不算锁住
- 把「要不要看见」写成用户本轮必须先答的作业

### 未消元

去年算不算核心、称谓认不认、格式外算不算单号：不是这一层抽象，继续停。

## Improvement Proposal

**Problem**: 031 用「请写一句」掩盖未锁完的抽象；本轮若再这么交，会把已经能锁的结构重新变成口语作业。

**Proposed Change**: 本 issue Consensus 维持 escalate-to-project，但删掉「用户自己写一句否则结构不算锁住」。结构以 032 / 033 为准；§4 四件只记「仍停住」。

**Design**:

```text
031 第 2 条作废（「若要，用户自己写一句」）。
024 / 031 里「交给用户的三件事」不得再当本轮作业清单。

本 issue 只准说：
  结构已锁，见 032 / 033。
  看见 / 题面 / schema / 去年称谓格式外：仍停住。
  角色不得代拟对外中文，也不得宣布采用任何手柄。

Consensus 出现下面任一情形即越权：
  · 把任何一句中文写成「本轮正式题面」
  · 把「现成有 / 现成没有」宣布为已采用的对外词
  · 要求用户先交一句题面，否则结构不算锁住
  · 把「要不要看见」写成用户本轮必须先答的作业
```

**Implementation Steps**:

1. Consensus 采用 escalate-to-project，理由写「剩余项是章程 §4 项目决定」，不要写「抽象没做完」。
2. 报告里四件标「仍停住」，不要标「请用户本轮回复」。
3. 不填写展示名、字段名、schema 补丁、推荐对外句。

**Risks**: 把 escalate 再读成「再开一轮找更顺的口语」；或把 033 内部手柄升格成已经采用的题面。

**Verification**:

