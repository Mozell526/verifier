# Charter — 第二问的边界必须按「看什么 / 不看什么」锁死

> 本轮只辩抽象，不重开 006–031 的对错结论，不改代码，不改协议正文。
> 用户否掉的不是再找一句更顺的口语。用户说：上一轮还是没把边界约束分清楚；
> 「今天就办不了吗」本身有歧义和语境偏差；是 / 不是 在该歧义下会导向另一个结果。
> 要求：思考正确抽象，把边界都弄清楚，并且没有任何可能的歧义。

## 1. Goal & Definition of Done

- Goal: 钉死第二问和「办成了没有」同级的判定对象、单位、以及「不看什么」；定义本身换语境不得翻面。
- Done:
  1. 每个根因一个 issue + 协议原文 + 失败对象对照；
  2. architect 独立重读协议后写 Consensus；
  3. 交给用户的是无歧义结构（单位 + 不看 + 三态 + 这不是什么），不是再找一句更顺的口语，也不是上线字段名，更不是让用户自己写题面。

「没有任何可能的歧义」的工作定义（可证伪）：

1. 定义里用的谓语，不能既可读成「这一次交付」，又可读成「产品里现成的那一档」；
2. 答第二问时，不得靠看这一次给没给到来得出答案；认「这种事」是哪一类时，只准看这一次请求，不准看这一次交付；
3. 漏做 ≠ 产品里现成没有那一档 ≠ 职责外 / 对象未成形；
4. 015 / 023 / 030 若对「第二问管多大一块」说法打架，本轮必须只留一套，并写明另外两套各降成什么。

## 2. Oracle

- **对错尺子**：`spec/alg/fulfilled.md` 第一章（只看一件事、三态、不区分没办成的原因、不新增第四态）、`spec/alg/authority.md` §1 / §8.2 / §8.3、`spec/alg/material-positioning.md` 不变量 1、`spec/info-volume.md`（不引入 partial、不需要第二套对错）、013–015 / 022–024 / 029–031 Consensus（死路仍死；但 015 / 023 / 030 对第二问适用范围的冲突由本轮收口）。
- **不是 oracle**：canvas、准确率、`is_supported=false`、空条件、「暂不支持」文案、常识功能地图、上一轮对外口语「今天就办不了吗」、上一轮内部手柄「定位内尚未具备 / 没有完成它的办法 / 正格」。
- 漏姓名 / 投保年 / 格式外编号 / 查天气 只当碰撞举例，不重判对错，不预填去年 / 称谓。

## 3. Red lines

## 4. Escalation

角色不得代选：

1. 要不要对外看见第二问
2. 用哪一句中文当对外题面
3. 现在改不改 schema
4. 去年算不算核心 / 称谓认不认 / 格式外算不算单号（仍停住）

本轮若结构已经锁住，看见与否只在报告里点一下「仍停住」，不要再把它写成用户必须先交的作业。

## 5. Evidence standards

- 协议原文 + 已锁 Consensus。不得用「我感觉更没有歧义」代替：单位对照、不看条款、换语境翻面测试。
- architect 必须自己重读 cited 协议，不抄 verifier 转述。
- 任一候选定义，若只看这一次交付就能答出它的正格，或能把漏做 / 职责外读进正格，即未达本轮「无歧义」。
- 030 的「正格 = 定位内 + 没有完成它的办法」本身要过本轮翻面测试；过不了就不能再当无歧义定义。
