## 1. Goal & Definition of Done

- Goal: 用正确抽象调判定代理。原则 / 标准 / 边界清楚，不要规则化。
  在内存里跑正常样本和坏样本，看哪种判定处理更好。
- Done:
  1. 原则正文：两问拆开；Q2 是“整句有没有被说清”，不是值等于整句；
  2. 内存实验注入到真正进模型的提示，而不是只挂在旁路片段；
  3. 关掉几何短路，测的是代理自己；
  4. 至少钉住：杨杰 / 王坤林 / 张伟 办成；共展 / 豆芽 没办成；
     红莲保单、唐诗颖生存金、只交了产品的“李明的重疾险”不得因姓名维被说成办成；
  5. 3–5 个新 issue（053+）；architect 独立重跑程序化脚本，不重跑全部大模型。

「不要有规则化」的工作定义：

1. 原则只许规定：看什么、不看什么、单位、封闭出口。对任意输入同一套。
2. 若必须先把问句分进预置类型再查表，即为规则化。
3. 若用残句为空 / 虚词表 / 点名样本才能落格，即为规则化。
4. 若把“值等于整句”卖成可泛化架构，即为规则化。
