# Report — 「尽力了」要不要单独开标签

用户把开关 2（去年）和 3（格式外/称谓）看成一类，想要一个偏产品定位的「尚未支持」，不要 fulfilled，也不要纯 IT。010–012 不重开。013–015 全部 Consensus = real-problem。

## 结论

2 和 3 不是一类。标签可以有，但不能跟办成了平级，也不能看今天系统拒了什么。

| issue | 共识 |
|---|---|
| 013 | 去年：主事已交、日期维未交。空条件：唯一对象没成形。不能共用整体格。 |
| 014 | 不新增第四态。尚未支持只挂在维上，或写进 NF/NE 的理由。评审整桶也算第四态。 |
| 015 | 没有产品功能地图之前，不得写尚未支持。`is_supported` / 空条件 / 「暂不支持」不能冒充地图。 |
