# Synthesis — 「尚未支持」标签（013–015，2026-08-15）

## 模式

用户觉得 2 和 3 像同一类「尽力了」。相似的是态度，不同的是失败对象。标签可以有，但不能跟办成了平级，也不能从今天系统拒了什么取值。

| 层 | issue | 钉什么 |
|---|---|---|
| 对象 | 013 | 去年（有核心交付）和空条件（没成形）不能共用整体格 |
| 词表 | 014 | 不新增第四态；尚未支持只挂在维上解释三态 |
| 证据 | 015 | 先有产品功能地图，再用已登记空间去减；实现侧信号不能冒充地图 |

## TOP 3

1. **先问主事交没交**。交了只剩附加点 → 走 007。没成形 → 走 009。
2. **整句仍是三态**。给业务看的「尚未支持」是维上的产品说明，不是新的总分。
3. **先补功能地图三个空格**，再谈标签：去年、称谓、残号。没有地图就不要写尚未支持。

## 留给用户

功能地图，不是新词：

1. 投保日 / 去年：客户搜索认不认？认的话是主事还是附加？
2. 称谓 / 老板娘：认不认？
